# Marrow & Moss

Marrow & Moss is an editorial boutique homeware storefront with an earthy visual identity, Unsplash-powered photography, product merchandising, responsive navigation, and a working client-side bag counter.

## Setup
`npm install && npm run dev`

## Vercel deployment

Import this repository into Vercel with the project root as the deployment root. The included `vercel.json` configures the Next.js framework, `npm ci` installation, and `npm run build` production command. Node.js 20 or newer is declared in `package.json`.
